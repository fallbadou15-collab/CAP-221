C'est quoi le Responsive Web Design ?

Un site responsive = une seule page HTML/CSS dont la mise en page s'adapte automatiquement à la taille de l'écran : ordinateur, tablette ou smartphone.

💻 Desktop

Large, paysage, souris

📱 Tablette

Intermédiaire, tactile

📱 Smartphone

Petit, portrait, pouce

2/9

Petit historique

  • Avant 2010 : sites en tableaux, puis versions séparées m.site.com (2 sites à maintenir !)
  • 2010 : Ethan Marcotte invente le terme « Responsive Web Design » (article A List Apart) — 3 ingrédients : grilles fluides, images flexibles, media queries
  • 2013+ : Bootstrap et les frameworks popularisent le responsive
  • 2015 : Google favorise les sites « mobile-friendly » dans son référencement
  • 2019 : Mobile-first indexing : Google indexe d'abord la version mobile

Comment ça marche concrètement ?

Media queries

@media (max-width: 768px) {
  menu → burger ☰
}

Le CSS change selon la largeur de l'écran.

Unités fluides

width: 50%
font-size: 1.2rem
image: max-width: 100%

Tout se redimensionne proportionnellement.

Mobile-first en CSS

/* base = mobile */
@media (min-width: 768px)
{ /* + pour desktop */ }

On part du plus petit écran.

👋 Démo live : on redimensionne un vrai site dans le navigateur !

Desktop vs Smartphone : les bonnes pratiques

💻 Desktop

  • Menu horizontal complet
  • Colonnes multiples, grilles larges
  • Hover (survol) possible
  • Beaucoup de contenu visible sans scroll

📱 Smartphone

  • Menu burger ☰
  • 1 colonne, empilement vertical
  • Cibles tactiles ≥ 44px (le pouce !)
  • Contenu calibré sur quelques scrolls
  • Images allégées → chargement rapide

Responsive vs Adaptive : deux écoles

💧 Responsive (80% du web)

  • Une seule page, mise en page fluide
  • C'est le navigateur qui adapte
  • La norme aujourd'hui
  • Ex : la plupart des sites actuels

🧱 Adaptive (l'ancienne école)

  • Plusieurs versions fixes prédéfinies, le serveur détecte l'appareil
  • Existe avant le responsive
  • Toujours utilisé par certaines grandes marques…

❓ Pourquoi ? Contrôle total sur chaque version + performances maximales sur mobile pour des sites à très fort trafic. Exemple : amazon.com vs m.amazon.com

À retenir 🐠

✅ Le responsive est la norme : un seul site qui s'adapte à tous les écrans

✅ On conçoit désormais en mobile-first : l'essentiel d'abord, puis on enrichit

✅ Google indexe le mobile en priorité : pas de responsive = pas de trafic

✅ L'adaptive survit chez quelques géants pour la perf et le contrôle
